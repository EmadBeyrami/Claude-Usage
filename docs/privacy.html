Privacy Policy

Last updated 2026.

Claude Usage is a macOS menu bar app and widget that shows your own Claude Code usage — session and weekly limit percentages, token counts, and estimated cost. This policy covers exactly what the app does with your data, because the honest answer is: nothing leaves your Mac except one request you already trust.

What the app reads

With your permission (granted once, through a macOS Open panel), the app reads a Claude Code config folder on your Mac — typically ~/.claude — to compute token counts and estimated cost from your own transcript files. It also makes one authenticated HTTPS request to api.anthropic.com/api/oauth/usage, using a Claude Code login token, to fetch your account's 5-hour and 7-day limit utilization.

What the app sends, and to whom

Nothing, except that one request to Anthropic's own API, made with your own credentials, to fetch your own numbers. The app has no server of its own. No analytics, no crash reporting, no telemetry, no advertising identifiers.

What's stored, and where

  • A small snapshot file (token counts, cost, limit percentages) is written to the app's own Application Support directory and to an App Group container shared only with this app's own widget extension — both stay on your Mac.
  • If you paste an access token into Settings (only needed for accounts where the token isn't already reachable in a file), it's stored in this app's own Keychain item, protected by macOS, and never written to disk in plain text or transmitted anywhere but the Anthropic request above.
  • Daily usage history is kept locally so charts survive Claude Code pruning old transcripts. It never leaves your Mac.

Third parties

The app optionally checks GitHub's public releases API for a newer version, purely informational — no personal data is included in that request, and nothing is downloaded or installed automatically.
